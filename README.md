# 访谈稿匿名化映射编辑器

在浏览器中对访谈稿进行匿名化：维护人物代号与称呼映射，自动识别称呼命中，支持鼠标框选显式指派与批量同文片段指派，可把个别称呼命中标为「保留原文」例外，并可将一位人物合并进另一位（称呼去重、框选与例外一并迁移，整次合并可原子撤销）。内置**敏感信息巡检**：离线识别原稿中的手机号、邮箱与 18 位身份证号（身份证校验出生日期与校验位），依据最终匿名映射实时判定每个候选为「已匿名 / 保留原文 / 仍泄漏」，可一键把仍泄漏项指派给已有人物。所有结果仅体现在匿名预览中，原稿永不改动，并维护原稿 ↔ 预览的双向字符区间映射。

## 一键启动（Docker Compose）

```bash
docker compose up --build
```

启动后在浏览器访问：**http://localhost:3000**

入口即首页：粘贴访谈稿点击「加载原稿，开始匿名化」，或点击顶部「加载内置示例」（示例稿内含一处手机号、一处邮箱与一处合法身份证号，可直接体验敏感信息巡检）。

> 端口固定为 `3000`（`docker-compose.yml` 中映射 `"3000:3000"`）。停止服务：`Ctrl+C`；后台运行：`docker compose up --build -d`。

不使用 Docker 时也可直接运行（需 Node.js 18+）：

```bash
npm install
npm start
# 访问 http://localhost:3000
```

## 操作说明

1. **粘贴原稿**：首页文本框粘贴访谈稿，点击「加载原稿，开始匿名化」；或点击顶部「加载内置示例」快速体验。
2. **维护人物规则**：在右侧填写「统一代号 + 称呼（多个用逗号分隔）」并添加人物。自动识别遵循**最长称呼优先**（长度相同则先出现者优先）。
3. **显式框选（最高优先级）**：在原稿中用鼠标框选任意片段，在弹窗中指派给已有或新建人物。框选可覆盖、切开任何称呼命中与保留原文例外。
4. **批量同文片段指派**：框选非空片段后，在弹窗中选好目标人物（含新建人物），点击「批量指派全文相同片段…」。确认弹窗按原稿**从左到右、互不重叠**地匹配全文完全相同的片段，并分类显示三档数量（互斥，合计为匹配总数）：
   - **可处理**：将新增为显式框选；
   - **与既有显式框选冲突**：跳过（同一匹配同时与框选、例外冲突时，按框选优先归入此类）；
   - **与保留原文例外冲突**：跳过。

   确认后**只新增可处理项**，冲突匹配一律跳过、不覆盖原有区间（与称呼命中的重叠不算冲突，因显式框选优先级更高）；整批变更（含随批量新建的人物）作为**一条撤销记录**，撤销即恢复操作前的区间集合与匿名预览。新增区间与手动框选完全等同，照常参与优先级裁决、双向映射、统计与映射表。
5. **保留原文例外**：
   - 在底部「字符区间映射表」中，对任一**称呼命中**行点击「保留原文」，该处即成为例外：预览中原样照录，并屏蔽与该区间重叠的所有自动称呼命中；
   - 右侧「保留原文例外」列表展示每个例外的**原稿片段**与**来源人物**（点击片段可在原稿/预览中定位）；
   - 点击例外列表或映射表中的「恢复匿名」即可删除例外、恢复自动匿名；
   - 若某例外被显式框选**完全覆盖**，列表中会置灰标注（被部分覆盖时，未覆盖部分仍然保留原文）。
6. **合并人物**：在人物列表中点击目标人物上的「合并」，在弹窗中选择要并入的**源人物**。弹窗会列出双方代号、去重后的称呼，以及将迁移的框选与保留原文例外数量；确认后源人物的称呼（去重）、框选与例外统一改绑到目标人物，源人物删除，重叠称呼仍按**最长称呼优先**处理。
7. **双向高亮**：点击或悬停原稿/预览中的高亮片段，可在两侧及映射表间联动定位；点击映射表行同样定位。
8. **敏感信息巡检**（侧栏「敏感信息巡检」）：
   - 加载原稿后**离线**扫描（无任何网络请求）手机号（`1[3-9]` 开头 11 位、两侧非数字）、邮箱与 18 位身份证号；身份证须同时通过**出生日期合法性**（公历、含闰年）与 **ISO 7064 末位校验码**；重叠候选按 **身份证号 ＞ 邮箱 ＞ 手机号、同类更长优先（长度相同取先出现者）** 去重；
   - 依据最终匿名映射把候选判为：**已匿名**（每个字符都被替换映射覆盖）、**保留原文**（无泄漏但落在「保留原文」例外中）、**仍泄漏**（存在照录进预览的字符，并列出泄漏子区间）；
   - 规则、框选、例外与人物合并等任何变化后状态**实时重算**；原稿/预览中以红 / 黄 / 绿下划线标记候选；
   - 侧栏可按状态筛选（全部 / 仍泄漏 / 保留原文 / 已匿名，含数量徽标），每条显示片段与**原稿区间**，点击即在原稿与预览中联动定位（悬停同样跨侧联动）；
   - 对单个**仍泄漏**项，可在条目内选择已有人物后点击「指派给人物」：按泄漏子区间补显式框选（已被既有框选覆盖的子区间不重复添加），复用显式框选优先级与**撤销栈**（整次指派一条记录）；指派后候选自动转判「已匿名」。
9. **撤销**：顶部「撤销最近操作」按时间倒序撤销，涵盖添加人物、显式框选、**批量同文指派（整批一条记录）**、**标记例外、恢复匿名、删除人物、合并人物、巡检指派**（删除人物会连同其框选与例外一并恢复；合并作为一次原子操作撤销，源人物按原 ID、原列表位置、原称呼及全部关联区间精确恢复；批量指派撤销时整批新增区间一并移除，随批量新建的人物也一并消失）。
10. **复制结果**：点击「复制匿名预览」复制匿名后的完整文本。
11. **重新粘贴**：点击「重新粘贴原稿」可清空全部规则、框选、例外与巡检结果后重新开始。

底部统计与映射表会随以上任何操作实时重算（人物数、框选 / 称呼 / 保留原文处数、被框选完全覆盖的例外数，以及敏感信息三态计数）。

## 目录结构

```
server.js            Express 静态服务 + /api/example 内置示例
example.json         内置示例数据（原稿 + 预置人物规则，含手机/邮箱/身份证示例）
public/anonymize.js  匿名化引擎（纯函数，浏览器/Node 共用）：匿名映射、批量匹配、
                     敏感信息识别 detectSensitive 与判级 classifyCandidates
public/app.js        前端交互（规则、框选、例外、撤销栈、敏感信息巡检、渲染）
public/index.html    页面结构
public/style.css     样式
```

巡检完全在浏览器本地完成，不向任何服务端发送原稿或识别结果；Docker Compose 仍是唯一的单命令启动方式（`docker compose up --build`，访问 http://localhost:3000）。
